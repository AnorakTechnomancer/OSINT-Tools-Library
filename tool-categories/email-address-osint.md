# Email Address OSINT

## Cost legend

- **Free** — the core tool is usable without payment.
- **Freemium** — some useful functionality is free, while additional results, volume, exports, automation, or advanced features require payment.
- **Paid** — meaningful use requires payment, credits, or a subscription.

> Pricing, rate limits, and access models change frequently. Use the individual tool page for detail and check its **Last verified** date as structured metadata is added across the library.

## How to choose

For a fast first pivot from an email, start with **Epieos**, **Zehef**, or **Zen** depending on the target ecosystem. For Google-specific investigation, **GHunt** is purpose-built. For broad enrichment across many identifiers and platforms, **OSINT Industries**, **Osintly**, or **Indicia** cover more ground but place more functionality behind paid access.

For professional/contact discovery, **AeroLeads** is oriented toward business data rather than general identity OSINT. **BeenVerified** is more appropriate for US-centric people/public-record research. Always corroborate account matches before treating them as attribution.
